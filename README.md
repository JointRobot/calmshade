# Calm Shade

**Calm Shade** is an invite-only homestay collective — "where even crows, look like birds" — for calm, taste-curated stays. Guests browse, chat, and book through one always-awake WhatsApp concierge (wa.me/918799938193); hosts keep 97% of every confirmed booking.

**Single-file app, deploy = copy `index.html`.** The entire product is one self-contained HTML file (media is base64-embedded, no build step, no dependencies, no framework) — it is deploy-ready as-is. See `HANDOVER.md` for the full operational handover (GitHub → Hostinger deploy, domain wiring, and the AI concierge proxy).
